# Excursion

Excursion is a landing page designed to advertise a mobile app that helps users record and share their travel experiences. Built with HTML and CSS, the page uses engaging video and landscape imagery to draw in potential users.

## Features
Responsive layout for desktop and mobile. Video and image-driven hero section. Clean, minimal marketing copy.

## Tech Stack
HTML, CSS

## Getting Started
Clone the repo and open index.html in your browser — no build step required.

## Status
Early-stage marketing/landing page project.
